# Chrome extension

Esta é a única superfície do usuário no MVP.

Responsabilidades futuras:

- iniciar a captura da aba somente após gesto explícito da pessoa usuária;
- manter o áudio local audível enquanto a captura está ativa;
- fornecer o stream ao detector local de atividade de fala;
- renderizar a sidebar de Counterpoint;
- permitir aceitar, ignorar, pesquisar ou pedir que o agente fale.

Não guarda credenciais e não se conecta diretamente a MCPs corporativos.
